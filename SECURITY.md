# Security policy / Sicherheitsrichtlinie

**English** · [Deutsch](#deutsch) · [Magyar](#magyar) · [Français](#français) · [Español](#español)

## Reporting a vulnerability

Please do **not** report security issues in public issues or discussions.

Report them privately via GitHub: open the **Security** tab of this repository and click
**Report a vulnerability**. Please include:

- the Passermark version (title bar or Help menu),
- operating system (Linux distribution or Windows version),
- what you did, what happened, and – if possible – a file or steps to reproduce it.

Passermark is a private project. I will acknowledge a report as soon as I can, usually within a few days, and
fix confirmed issues in the next release. There is no bug bounty.

## Supported versions

Only the latest release receives fixes. Please check that the issue still occurs there.

## Scope

Relevant are, for example: files (PDF, images, Office documents, CSV, presets) that make Passermark execute code
or write outside the chosen location; problems in the Windows installer or the Linux installation (`install.sh`,
the admin helper); leaking of data from print jobs or settings.

Kérjük, biztonsági problémákat **ne** nyilvános issue-kban vagy megbeszélésekben jelents.

Helyette bizalmasan, GitHubon: a repó **Security** fülét megnyitni és a **Report a vulnerability** gombot

Linux-telepítésben (`install.sh`, az admin-segédprogram); nyomtatási feladatokból vagy beállításokból
kifelé kerülő adatok.

- qué hiciste, qué ocurrió y – si es posible – un archivo o pasos para reproducirlo.

y corregiré los problemas confirmados en la próxima versión. No hay recompensa por errores.

### Versiones compatibles

Solo la última versión recibe correcciones. Por favor, comprueba antes que el problema siga ocurriendo allí.

### Alcance

Son pertinentes, por ejemplo: archivos (PDF, imágenes, documentos de Office, CSV, preajustes) que hagan que
Passermark ejecute código o escriba fuera de la ubicación elegida; problemas en el instalador de Windows o en
