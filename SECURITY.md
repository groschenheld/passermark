# Security policy / Sicherheitsrichtlinie

**English** · [Deutsch](#deutsch)

## Reporting a vulnerability

Please do **not** report security issues in public issues or discussions.

Report them privately via GitHub: open the **Security** tab of this repository and click
**Report a vulnerability**. Please include:

- the Passermark version (title bar or Help menu),
- operating system (Linux distribution or Windows version),
- what you did, what happened, and – if possible – a file or steps to reproduce it.

Passermark is a private project. I will acknowledge a report as soon as I can, usually within a few days, and
fix confirmed issues in the next release. There is no bug bounty.

## Supported versions

Only the latest release receives fixes. Please check that the issue still occurs there.

## Scope

Relevant are, for example: files (PDF, images, Office documents, CSV, presets) that make Passermark execute code
or write outside the chosen location; problems in the Windows installer or the Linux installation (`install.sh`,
the admin helper); leaking of data from print jobs or settings.

## Deutsch

### Sicherheitslücke melden

Bitte Sicherheitsprobleme **nicht** in öffentlichen Issues oder Diskussionen melden.

Stattdessen vertraulich über GitHub: im Repository den Reiter **Security** öffnen und
**Report a vulnerability** wählen. Bitte angeben:

- die Passermark-Version (Titelleiste bzw. Hilfe),
- Betriebssystem (Linux-Distribution oder Windows-Version),
- was du gemacht hast, was passiert ist und – wenn möglich – eine Datei oder Schritte zum Nachstellen.

Passermark ist ein privates Projekt. Ich bestätige eine Meldung so bald wie möglich, meist innerhalb weniger
Tage, und behebe bestätigte Probleme in der nächsten Version. Es gibt keine Prämie.

### Unterstützte Versionen

Nur die jeweils neueste Version bekommt Korrekturen. Bitte vorher prüfen, ob das Problem dort noch auftritt.

### Was dazugehört

Zum Beispiel: Dateien (PDF, Bilder, Office-Dokumente, CSV, Presets), die Passermark dazu bringen, Code
auszuführen oder außerhalb des gewählten Orts zu schreiben; Probleme im Windows-Setup oder in der
Linux-Installation (`install.sh`, das Admin-Hilfsprogramm); Daten aus Druckaufträgen oder Einstellungen, die nach
außen gelangen.
